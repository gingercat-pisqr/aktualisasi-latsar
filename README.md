# WEBSITE AKTUALISASI LATSAR
# Automatic Assignment untuk Kasus Permohonan Pemeriksaan ke Pemeriksa

Website ini berfungsi sebagai alat untuk melakukan monitoring kasus permohonan pemeriksaan untuk tiap tim di seksi P3 KPP Pratama Jakarta Tanah Abang Dua.
Website ini dapat dijalankan secara offline dan dapat terhubung dengan interkoneksi Portal P2 agar memudahkan dalam interkoneksi data.
